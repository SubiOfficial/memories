# Background music

The active track is `mehabooba.mp3`, set in `src/config/music.ts` as `CURRENT_TRACK`.

To swap or add a new song: drop the mp3 file here in `public/audio/`, then update
`CURRENT_TRACK` in `src/config/music.ts` to that filename. The play/pause toggle in the
toolbar and the infinite loop behavior work automatically — no other code changes needed.
